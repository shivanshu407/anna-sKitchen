# Local font sources

These are unmodified official Google Fonts Latin variable WOFF2 files, distributed with their SIL Open Font License 1.1 notices.

Requested [Google Fonts CSS](https://fonts.googleapis.com/css2?family=Inter:wght@300..800&family=Outfit:wght@400..900&display=swap) with a complete modern Chrome user agent to receive WOFF2.

- Inter, normal Latin variable, weights 300 800: [original WOFF2](https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7.woff2), [official SIL OFL license](https://raw.githubusercontent.com/google/fonts/main/ofl/inter/OFL.txt). Downloaded 2026-10-02; 48256 bytes.
- Outfit, normal Latin variable, weights 400 900: [original WOFF2](https://fonts.gstatic.com/s/outfit/v15/QGYvz_MVcBeNP4NJtEtq.woff2), [official SIL OFL license](https://raw.githubusercontent.com/google/fonts/main/ofl/outfit/OFL.txt). Downloaded 2026-10-02; 32292 bytes.

Run `node scripts/build-seo-assets.mjs` to copy the fonts and licenses into `public/fonts/`. Builds do not download fonts.
